# 自动下载助手

用户脚本（Tampermonkey / Violentmonkey），在下载页批量选择链接，依次打开并自动完成下载。

## 一键安装

[安装脚本](https://raw.githubusercontent.com/WuLinLee/auto-download-assistant/main/auto-download-assistant.user.js)

点击上方，脚本管理器会自动弹出安装确认框，点击「安装」即可。

## 功能

- 自动生成下载面板，列出所有 fuckingfast 链接
- 全选 / 取消全选 / 勾选指定项
- 批量下载：逐个前台打开，自动点击 fuckingfast 下载按钮，完成后关闭并处理下一个
- 界面支持 English / 中文
